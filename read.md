Laporan debugging

Saya melakukan debugging dengan menggunakan DEVTool melalui CTRL + SHIFT + I atau F12. Kemudian akan muncul bar Elements, Console, dan network. Elements adalah sekumpulan kode yang fokus di HTML dan CSS yang bisa diedit sementara secara realtime dan jika di refresh maka tampilannya berubah kembali ke awal karena itu hanya sebagai debug untuk menentukan yang mana salah atau berfungsi dengan baik. Console adalah menunjukkan log yang memberi tau apa yang error dalam sebuah website atau error dalam javascript, ini bisa dilakukan dalam java script jika ingin mengecek apakah kode ini berfungsi dengan semestinya atau tidak. Network berfungsi untuk menunjukkan kecepatan responsif dan menunjukkan jika ada bagian dari website itu yang tidak bisa bekerja seperti 404 yang tidak menemukan halaman. 

dalam praktikum ini saya sudah mencoba menggunakan devtool yang dimana saya dengan sengaja membuat typo dalam kode href css untuk melihat apakah devtool bisa mendeteksinya dan ketika saya membuka inspect dan console dan network, maka ditemukan ada error dan css dalam keadaan 404. 


Sekian refleksi saya tentang Devtool dalam elements, console, dan network. Ini sepenuhnya pengetahuan yang saya dapat dari praktikum yang saya kerjakan di 10/9/2026.
